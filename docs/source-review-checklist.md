# Source Review Checklist

Use this checklist when real, reviewable material is ready to be entered. Leave fields blank when information is not documented; do not infer a value to complete the form.

## Source Identification

- [ ] Title/name
- [ ] Publisher/institution
- [ ] Author/artist, if documented
- [ ] Date, if documented
- [ ] URL/catalog/reference information
- [ ] Source type

## Attribution

- [ ] Artist
- [ ] Community
- [ ] Institution
- [ ] Photographer/documenter, where relevant
- [ ] License/usage information

## Evidence

- [ ] Exact reference being documented
- [ ] Visible motif
- [ ] Documented context
- [ ] Observation
- [ ] Uncertainty

## Grammar Interpretation

- [ ] Repeated occurrence
- [ ] Structural relationship
- [ ] Possible rule
- [ ] Confidence
- [ ] Supporting references

## Validation

- [ ] Multiple references, where appropriate
- [ ] Conflicting evidence
- [ ] Exceptions
- [ ] Uncertainty
- [ ] Review status
